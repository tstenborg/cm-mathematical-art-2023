# CARMA-MATRIX Mathematical Art 2023

[![super-linter](../../actions/workflows/super-linter.yml/badge.svg)](../../actions/workflows/super-linter.yml) ![human-only art](https://img.shields.io/badge/human--only-art-white)

Second place award-winning entry for the CARMA-MATRIX mathematical art 2023
competition [[1](#references)], [[2](#references)], [[3](#references)].
_Apollonian Sunset_ merges a fractal Apollonian gasket with a synthwave sunset
(retrosun). The entry was computer-aided art, but not generative AI art. It is
available here in various file formats and sizes. Digital display and physical
printing are both supported.

## Getting Started

### Physical Printing

The files intended for physical printing are 300 ppi, 16-bit CMYK colour, PDF
files with 3 mm bleed margins and trim marks.

The PDF files are compressed in ZIP format. If your system doesn't natively
support ZIP extraction, a ZIP tool will be needed (e.g.,
[7-Zip](https://www.7-zip.org), [WinRAR](https://www.win-rar.com),
[WinZip](https://www.winzip.com)).

### Digital Display

The file intended for digital display is a 1200 &times; 900 pixel, 300 ppi,
8-bit RGB colour, PNG file.

An example HTML file displaying _Apollonian Sunset_ is
[available here](src/apollonian-sunset.html).
